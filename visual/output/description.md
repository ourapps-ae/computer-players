# Computer players

The computer-players component at version 0.5.1 provides ae/computer-players version 1.0.0 to an illustrative application consumer, which in turn supplies ae/player-strategy version 1.0.0 and ae/game-clock version 1.0.0 and ae/seating version 1.0.0. The 4 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
